# GUI 证明操作指南：∀ x : N , ( ADD ( ( ADD ( x , _0 , ) ) , _0 , ) ) = x

> 目标：在 `forend-logicy2-1` 图形界面中完成上述定理的证明。
> 依据：`dev/modeling/ui/forend_logic_y2_1_modeling.md`（§4 行为视图与操作→端点映射）、`interface/interface.yaml`。

## 前置条件

- 后端 `http://127.0.0.1:5000`、前端 `http://localhost:3000` 已启动。
- 预定义已载入（`ADD`、`_0`、公理 `∀ x : N , ( ADD ( x , _0 , ) ) = x` 出现在「定理/公理」面板）。
- 界面与后台的结论编号一致，均从 0 开始；证明步骤序号与结论序号一致（`Context.lines` 恒为空，`LN` 不参与编号）。

## 操作步骤

1. **设定目标**：命令行输入
   ```
   theorem ∀ x :N,  (ADD ((ADD (x,_0,)),_0,)) = x
   ```
   回车 → 模式进入 Proof，待证目标固定。

2. **声明自由变量**：输入
   ```
   any x : N,
   ```
   回车 → 变量面板出现 `x : N`。

3. **引用公理**：在「定理/公理」面板**右键**公理
   `∀ x : N , ( ADD ( x , _0 , ) ) = x`（触发 `/use`）→ 生成**结论 0**。

4. **造辅助项 `tx`**：在结论 0 中选中最右端的 `x`（`= x` 的那个 x），**等 3 秒**让 `/cp2tp` 返回，在「辅助项」待定区命名 `tx`，添加。

5. **量词消去**：规则「量词消去」。约束变量填 `x`；参数区拖入 `tx`；结论 ID 拖入**结论 0**；应用 → **结论 1**：
   ```
   ( ADD ( ( x ) , _0 , ) ) = ( x )
   ```

6. **造辅助项 `tadd`**：在结论 1 中选中
   ```
   ADD ( ( x ) , _0 , )
   ```
   —— **不要选最外层括号**，等 3 秒，命名 `tadd`，添加。

7. **再次量词消去**：约束变量 `x`；参数拖入 `tadd`；结论 ID 拖入**结论 0**；应用 → **结论 2**：
   ```
   ( ADD ( ( ADD ( ( x ) , _0 , ) ) , _0 , ) ) = ( ADD ( ( x ) , _0 , ) )
   ```

8. **等式替换**：规则「等式替换」。等式 ID 拖入**结论 1**；结论 ID 拖入**结论 2**；方向选「用右端替换左端」（old_side=左）。然后在结论 2 中选中右式的
   ```
   ( ADD ( ( x ) , _0 , ) )
   ```
   —— **含最外层括号**，等 3 秒让起止位置自动填充，应用 → **结论 3**：
   ```
   ( ADD ( ( ADD ( ( x ) , _0 , ) ) , _0 , ) ) = ( x )
   ```

9. **去括号**：规则「括号操作 → 去除括号」。在结论 3 中选中右式 `( x )`（含括号），等 3 秒，应用 → **结论 4**：
   ```
   ( ADD ( ( ADD ( ( x ) , _0 , ) ) , _0 , ) ) = x
   ```

10. **再去一层括号**：在结论 4 中选中 `( ADD ( ( x ) , _0 , ) )` 内层的 `( x )`，等 3 秒，应用 → **结论 5**：
    ```
    ( ADD ( ( ADD ( x , _0 , ) ) , _0 , ) ) = x
    ```

11. **量词引入**：规则「量词引入」。
    - **把结论 5 卡片拖进「结论 ID」输入框**（不要只手动输入数字，手输不会带 `conclusion_id`，请求会失败）；
    - 量词选 `∀`；
    - 从变量面板把 `x` 拖入映射区，绑定名填 `x`；
    - 应用 → **结论 6**：
      ```
      ∀ x : N , ( ADD ( ( ADD ( x , _0 , ) ) , _0 , ) ) = x
      ```

12. **结束证明**：规则「结束证明（qed）」→ 应用。模式回到 Global，证明完成。

## 关键注意点

- **选区延时**：每次鼠标选区后 `/cp2tp` 固定 3 秒才返回，且没有取消机制。未返回前添加辅助项或应用表单会使用旧/空选区。
- **括号边界**：
  - 第 6 步造 `tadd`：选区**不含**最外层括号；
  - 第 8、9 步的替换/去括号目标：选区**必须含**最外层括号。
- **`introduce` 载荷**：结论 ID 必须通过**拖动结论卡片**写入；手输数字时 UI 载荷缺少 `conclusion_id`。
- **`qed` 精确匹配**：`Context.qed` 对目标与最后结论做逐字符比对，空格与括号均参与比较。若报不匹配，先对齐结论 6 与目标文本，必要时再对多余括号执行「去除括号」。

## 附：后台等价的调用序列（用于排查）

以 0 基结论 ID 表示（结论 0 = 引用公理后的结果）：

```
use axiom <公理名>                                   -> C0
select C0 [15..15] -> add_term tx                    // 最右端 x
instance C0 {x: tx}                                  -> C1
select C1 [1..9]  -> add_term tadd                   // ADD ( ( x ) , _0 , ) 不含外层括号
instance C0 {x: tadd}                                -> C2
eqrepl equal=C1, conclusion=C2, old_side=left,
       select C2 [20..30]                            // ( ADD ( ( x ) , _0 , ) ) 含外层括号
                                                     -> C3
bra off, select C3 [20..22]                          // 右式 ( x )
                                                     -> C4
bra off, select C4 [6..8]                            // 内层 ( x )
                                                     -> C5
introduce conclusion=C5, quantifier=∀, free_bound={x: x}
                                                     -> C6
qed                                                  -> mode Global
```

验证结果（实测）：

```
FINAL: ∀ x : N , ( ADD ( ( ADD ( x , _0 , ) ) , _0 , ) ) = x
TARGET: ∀ x : N , ( ADD ( ( ADD ( x , _0 , ) ) , _0 , ) ) = x
MATCH: True
MODE: Global
```
